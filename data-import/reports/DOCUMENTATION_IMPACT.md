# AIMS User Manual Impact

- Asset Management: explain automatic lifecycle-event creation and technical metadata visibility.
- Asset Detail: document the embedded History experience and absence of a separate sidebar module.
- History: describe search, type/date/user/source filters, immutable system events and correction events.
- Maintenance: note that create/start/complete actions append asset lifecycle events.
- Repairs: document issue, solution and outcome history links.
- Movements: document before/after location and department evidence.
- Assignments: document assignment and return lifecycle evidence.
- Disposal: document requested, approved, completed and archived events.
- Data Import: explain dry-run, source authority, duplicate review, idempotency and approval before production writes.
- Security: document history permissions, restricted AnyDesk/TeamViewer visibility and permanent administrator-password exclusion.
