# Presentation Known Limitations

- Browser persistence and authentication are simulated.
- Files, notifications and the AI Assistant are mock implementations.
- No permanent database, Firebase Security Rules or trusted backend enforcement exists.
- Audit, report, notification and administration route families remain partial.
- Demo personas approximate stakeholder roles using the current seven-role permission model.
- Offline support caches the application shell; it is not production synchronization.
- No real KCS staff, inventory or operational records are included.
- The build is local and not deployed.
- Accessibility/browser evidence is automated and not an external certification.
- Demo reset affects only the in-memory mock repository for the active browser session.
