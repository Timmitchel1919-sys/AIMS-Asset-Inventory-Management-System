# AIMS Brand Identity

Public AIMS branding always uses Deep Navy `#071F3D`, Enterprise Blue `#2C7EF4`, Deep Blue `#155EEF`, Cyan `#00AEEF`, and Ice Blue `#D5EFFE`.

Authenticated `aimsEmeraldGlass` surfaces use the reusable `AimsLogo` vector in Forest, Emerald, bright green, and mint. Public and authentication contexts always render the existing approved blue master logo. The installed PWA manifest and operating-system icon remain blue regardless of the internal preference.
