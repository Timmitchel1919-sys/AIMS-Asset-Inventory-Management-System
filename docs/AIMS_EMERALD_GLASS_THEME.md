# AIMS Emerald Glass

`aimsEmeraldGlass` is an authenticated-system-only theme. Its palette is Forest `#0D2B1E`, Emerald `#146C43`, bright green `#2ECC71`, mint `#D9F3E3`, slate `#64748B`, gray `#F2F5F7`, and white `#FFFFFF`.

Protected surfaces use translucent white glass with green borders, 16–18px blur, and solid white/forest fallbacks. Primary actions use the approved permanent glossy gradient. Mobile uses higher surface opacity and 10px blur. Reduced-transparency mode removes blur.

The authenticated preference is stored under `authenticatedThemePreference`. Legacy Forest Gold preferences migrate to Emerald. Operational status tokens remain centralized and unchanged.
