# AIMS Azure Glass theme

The public page identifies itself with `data-theme="aimsAzureGlass"` and uses the official palette: deep navy `#071F3D`, enterprise blue `#2C7EF4`, deep blue `#155EEF`, cyan `#00AEEF`, ice blue `#D5EFFE`, slate `#536B82`, mist `#F4F8FC`, white, and near black.

Glass surfaces use a white 78% base, a low-contrast enterprise-blue border, 16px blur with 135% saturation, and a restrained navy shadow. Primary and install actions permanently use the approved blue-to-cyan glossy gradient. Reduced-transparency mode replaces translucent surfaces with opaque equivalents.
# Public-theme guarantee

`aimsAzureGlass` is the permanent effective theme for the landing page, authentication, legal/support, and public download routes. Internal theme selection never replaces the official blue public identity or installed PWA icon.
