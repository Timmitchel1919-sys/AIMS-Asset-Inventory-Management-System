# AIMS visual direction

## Character

Confident, tactile and precise. Avoid toy-like shine, heavy glass blur and exaggerated motion.

## Signature rules

- Primary module context is large and unmistakable on desktop, but remains compact on phones.
- Search has a clear two-pixel brand outline and a visible WCAG-oriented focus ring.
- Buttons use restrained vertical light, an inset highlight and two low-opacity depth shadows.
- Hover raises controls by one pixel; active state compresses the shadow instead of scaling the control.
- Dark and light themes inherit the same finish through existing semantic color tokens.

## Do

- Preserve readable text contrast and recognizable destructive colors.
- Keep gloss subtle enough for dense tables and operational screens.
- Respect reduced-motion preferences.

## Do not

- Add animated glare, high-intensity neon, translucent text or large hover scaling.
- Apply overlay styling to scrims and modal backdrops.
