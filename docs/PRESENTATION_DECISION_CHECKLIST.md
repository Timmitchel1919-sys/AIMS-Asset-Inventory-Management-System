# Presentation Decision Checklist

Record owner, decision, date and approval evidence for:

- [ ] Official departments and hierarchy
- [ ] Official campuses, rooms and storage locations
- [ ] User roles, permission matrix and record scopes
- [ ] Approval and segregation-of-duties rules
- [ ] Asset-code groups and allocation authority
- [ ] Mandatory asset/inventory fields
- [ ] Borrowing, return and overdue rules
- [ ] Repair approval, cost and completion rules
- [ ] Maintenance frequencies and responsibility
- [ ] Audit frequency, sample method and adjustment approval
- [ ] Mandatory management/operational reports
- [ ] Data owners, migration sources and quality sign-off
- [ ] System owner and first production administrator
- [ ] Firebase Phase 10 authorization
- [ ] Staging/pilot and production deployment approval

Unresolved decisions become tracked feedback; presentation approval does not itself authorize Firebase or deployment.
