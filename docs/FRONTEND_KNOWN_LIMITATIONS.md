# Frontend Known Limitations

- 89 manifest routes remain partial, especially Waves 6–8.
- Authentication, persistence, notifications, files and AI are mock implementations.
- Route permissions are not complete trusted repository authorization.
- Department/location/record and sensitive-field policy is incomplete.
- Activity schema/category coverage is incomplete.
- Four themes exist; Wave 9 requires five-theme certification.
- Offline support is an application shell, not conflict-safe offline synchronization.
- Installability, update flow, all-route accessibility/responsive behavior and real-device behavior lack current complete certification.
- Browser storage is resettable and unsuitable for sensitive production records.
- File validation, upload storage and malware scanning do not exist.
- Firebase architecture documents are plans, not implemented or emulator-tested controls.
- No independent WCAG/security/privacy/legal/license review has occurred.
